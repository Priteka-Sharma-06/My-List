# My List ✅

A clean, minimal to-do list app with a warm aesthetic — built with vanilla HTML, CSS, and JavaScript.

## Features

- Add tasks instantly
- Check off completed tasks with a custom checkbox
- Delete tasks with the × button
- Live counter showing remaining vs total tasks

## Tech Stack

- HTML5
- CSS3 (custom properties, transitions, glassmorphism)
- Vanilla JavaScript (DOM manipulation, event listeners)
